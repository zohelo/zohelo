# zohelo.com

The brand website, on Cloudflare Pages (React + Vite + Tailwind). Platform documentation for all
zohelo products: [docs/](docs/README.md).

```bash
bun install
bun run dev      # http://localhost:3000 (quotes use a sandbox token through the dev proxy)
bun run build
```

Deployed by `.github/workflows/deploy.yml` on every push to `main`.
